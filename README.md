# 🎓 FuckUESTCCourse

一个用于课程视频页面的浏览器用户脚本。用于硕士新生学习。但是对于网站上其他需要刷课的内容通用

脚本基于 **Tampermonkey（篡改猴）** / **Violentmonkey（暴力猴）** 运行，可以自动检测课程视频播放状态，并提供悬浮控制面板、运行日志、倍速控制等功能。

> 本项目仅通过网页现有播放器进行正常的播放、暂停、倍速和“下一个学习内容”等操作，不修改服务器数据，也不伪造课程完成状态。

---

## ✨ 功能

目前支持：

- ✅ 自动识别未完成课程
- ✅ 自动进入未完成课程
- ✅ 自动开始播放视频
- ✅ 视频意外暂停后自动继续播放
- ✅ 视频结束后自动点击 **“下一个学习内容”**
- ✅ 自动继续播放下一个视频
- ✅ 找不到“下一个学习内容”时重新扫描课程列表
- ✅ 自定义视频播放倍速
- ✅ 自动记忆上一次设置的播放倍速
- ✅ 页面右下角悬浮控制面板
- ✅ 实时显示脚本运行日志
- ✅ 支持手动点击“播放”
- ✅ 支持手动点击“下一项”
- ✅ 可以开启/关闭“暂停自动继续”
- ✅ 可以开启/关闭“自动下一项”

# 📦 安装

使用本脚本前，需要先安装一个浏览器用户脚本管理器。

推荐：

- Tampermonkey（篡改猴）
- Violentmonkey（暴力猴）

Microsoft Edge、Chrome、Firefox 等浏览器均可以使用。

---

# 方法一：使用 Tampermonkey（篡改猴）

## 1. 安装 Tampermonkey

## 2. 创建新脚本

点击浏览器右上角：

```text
Tampermonkey
```

然后选择：

```text
添加新脚本
```

或者：

```text
Create a new script
```
---

## 3. 删除默认内容

将编辑器中的内容全部删除。

---

## 4. 粘贴脚本

复制本项目中的脚本文件，例如：

```text
user.js
```

将完整代码粘贴到 Tampermonkey 编辑器。

---

## 6. 保存脚本

按：

```text
Ctrl + S
```

或者点击：

```text
文件 → 保存
```

确保 Tampermonkey 中脚本状态显示为：

```text
已启用
```

# 🚀 使用方法

## 第一步：登录学习网站

先正常登录课程网站。

进入课程页面：

```text
https://resource.uestc.edu.cn/
```

---

## 第二步：等待脚本启动

登录新生学习课程网页，页面加载完成以后，右下角会出现：

```text
课程自动播放助手
```

悬浮控制面板。

如果悬浮窗正常出现，说明脚本已经成功加载。

**注意：第一次进入或刷新页面后需要手动进行一次点击，点一次播放**

---

# 🖥 悬浮控制面板

悬浮窗口主要包含：

```text
课程自动播放助手

状态：播放中 16x

倍速：[ 16 ] [设置] [播放] [下一项]

☑ 暂停自动继续
☑ 自动下一项

```

点击右上角：

```text
−
```

可以折叠悬浮窗。

再次点击：

```text
+
```

可以展开。

---

# ⚡ 设置播放倍速

在：

```text
倍速
```

输入框中输入需要的播放速度。

例如：

```text
1
```

表示：

```text
1x
```

正常速度。

输入完成以后点击：

```text
设置
```

来修改 HTML5 视频播放速度。 **注意：最高不能超过16倍速不然会报错**
